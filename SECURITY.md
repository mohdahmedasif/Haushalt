# Security

Haushalt stores the ledger in a local SQLite file. Treat that file like a bank statement.

## Do not file in public issues

- Bank CSVs
- IBANs, account numbers, or transaction rows
- `.env` contents or API keys
- Copies of `data/haushalt.sqlite`

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mohdahmedasif/haushalt/security/advisories/new) so bank-related details stay off the public issue tracker.
